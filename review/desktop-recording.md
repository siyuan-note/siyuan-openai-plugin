# ChatGPT 桌面 CLI 技能录屏分镜

用一个合成工作空间完成录制。提前准备 Planning 笔记本和 Launch Checklist，正文包含 `The cobalt launch rollout date is 12 February 2027.`。在系统终端确认 `siyuan --version` 成功。

| 画面与操作 | 可核对结果 |
| --- | --- |
| 在 ChatGPT 桌面应用打开已安装的 SiYuan 插件，再新建本地会话 | 展示插件名称和 SiYuan 技能 |
| 选择合成工作空间 | 录到用户明确选择工作空间 |
| 搜索并读取 Launch Checklist | 找到 12 February 2027，并引用思源来源 |
| 在 Planning 中新建 Plugin Live Notes | 创建选定笔记本中的文档 |
| 追加一句话，再读回这篇笔记 | 展示已有内容和追加内容，切到思源确认刷新后的正文 |
| 向不存在的文档 ID 追加 | 报告缺失、原笔记保持原样 |

```text
Find my SiYuan notes that mention the cobalt launch, then tell me the rollout date and cite the original note.

Create a document named Plugin Live Notes in the Planning notebook and add the sentence The first QA review is scheduled.

Append the sentence QA approved the checklist to Plugin Live Notes in SiYuan, then read back the full document.

Append The review marker must not be written to the SiYuan document with ID 20270115100000-miss001. If you cannot find that exact document, report that it is missing.
```
